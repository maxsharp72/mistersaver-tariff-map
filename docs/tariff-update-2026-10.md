# Обновление тарифов ЖКУ: индексация 1 октября 2026

**Версия плагина:** 0.2.25
**Дата обновления данных:** 16.11.2026
**Тип обновления:** ручной (парсер из `tariff-updater-spec-v2.md` ещё не реализован)

---

## 1. Что произошло 1 октября 2026

В 2026 году индексация платы за ЖКУ прошла в два этапа:

| Этап | Дата | Рост | Основание |
|---|---|---|---|
| Технический | 1 января 2026 | +1,7% по всем регионам | повышение НДС с 20% до 22% |
| Основной | 1 октября 2026 | от 8% до 22% по регионам, в среднем по РФ +9,9% | распоряжение Правительства РФ от 25.11.2025 № 3413-р (с поправками сентября 2026, в т.ч. № 2633-р от 24.09.2026) |

В сентябре 2026 индексы были пересмотрены в сторону повышения для шести регионов: Кемеровская область (12% → 19,8%), Марий Эл (9,4% → 14,9%), Краснодарский край (9,6% → 13,7%), Якутия (15% → 18,9%), Бурятия (8,9% → 12,3%), Волгоградская область (9,4% → 11,2%). В данных учтены пересмотренные значения.

**Важно:** индекс ограничивает рост **совокупного платежа**, а не каждого тарифа. Отдельные тарифы растут по-разному. Пример Москвы: ХВС +10,4%, водоотведение +14,8%, ГВС +18,9%. Поэтому пересчитывать тарифы по воде, теплу и газу единым индексом **нельзя**.

## 2. Что обновлено в `data/regions-tariffs.json`

### 2.1. `index_2026`: средний индекс роста с 01.10.2026, 85 регионов

Заполнен для всех субъектов, перечисленных в распоряжении № 3413-р. Для ДНР, ЛНР, Запорожской и Херсонской областей индекс в распоряжении не установлен, поле не заполнено, и строка 2026 в карточке индексации для них скрыта.

Источники: [vbr.ru (таблица по всем регионам с сентябрьскими поправками)](https://www.vbr.ru/novosti/jkh/2026/09/29/tarifi-jkh-s-1-oktyabrya-2026/), [Гарант](https://www.garant.ru/news/1914270/), [Интерфакс: в среднем +9,9%](https://www.interfax.ru/russia/1119513).

### 2.2. `electricity`: одноставочный тариф с 01.10.2026, 85 регионов

Определение поля: **одноставочный тариф для городского населения в домах с газовыми плитами, 1-й диапазон потребления, руб./кВт·ч с НДС**.

- 83 региона: сводная таблица по решениям региональных регуляторов, сверенная 08.10.2026, [romanfink.ru](https://romanfink.ru/reference/energetika/tarify-na-elektroenergiyu/). Там же указаны реквизиты решения по каждому региону.
- Крым: 5,45 (приказ Госкомцен РК от 29.12.2025 № 47/5), [Крымэнерго](https://crimea-energy.ru/about/news/13525-01-15).
- Севастополь: 5,71 (приказ Управления по тарифам от 19.12.2025 № 144-УТ), [acrimea.com](https://acrimea.com/articles/zkh-tariffs-26-sev-2026).
- ДНР, ЛНР, Запорожская и Херсонская области: **не обновлены**.

> Выявлено: прежние значения `electricity` (июль 2025) заметно расходились с официальными тарифами того же периода: по медиане были занижены примерно на 19%, а разброс составлял от −17% до +122%. Например, в Якутии в датасете было 4,35 при фактических ~9,66, в Алтайском крае 5,25 при ~6,25. Датасет 0.2.24 для большинства регионов (кроме Москвы, СПб, Крыма, Севастополя и новых регионов) содержал оценочные или округлённые значения, а не данные регуляторов. Вероятно, то же касается воды, тепла и газа, поэтому их нужно перепроверить в первую очередь.

### 2.4. `bill`: средний платёж, 85 регионов (оценка)

`bill_new = round(bill_old × 1,017 × (1 + index_2026 / 100))`, то есть январский шаг +1,7% плюс октябрьский индекс региона. Для всех пересчитанных регионов выставлен флаг `bill_estimated = true`, и в тултипе карты значение помечается как оценка. Среднее по 89 регионам: около 6 070 ₽, медиана около 5 700 ₽ (KPI на карте: 5 700 ₽).

`tier` (цветовой класс региона) не пересчитывался: относительное ранжирование регионов практически не меняется.

## 3. Что НЕ обновлено (требует следующего прохода)

| Поле | Регионы | Почему |
|---|---|---|
| `water`, `hot_water`, `wastewater` | все, кроме Москвы, СПб, Севастополя | тарифы устанавливаются по каждому водоканалу; нужен посубъектный сбор по приказам регуляторов |
| `heat` | все, кроме Москвы, СПб, Севастополя | аналогично, по теплоснабжающим организациям |
| `gas` | все, кроме Москвы, СПб, Севастополя, МО | нужен сбор по региональным газовым компаниям |
| `garbage` | все | в ряде регионов (в т.ч. Москва) ТКО начисляется с м², а не с человека; методика поля требует уточнения |
| `electricity_night` | 80 регионов | нет сводного источника по зонным тарифам |
| ДНР, ЛНР, Запорожская, Херсонская обл. | все поля | отдельный режим регулирования, индекс в № 3413-р не установлен |

Для регионов, где обновлена только электроэнергия, `tariff_date` оставлен `2025-07-01`, чтобы не заявлять актуальность для необновлённых тарифов.

Это первоочередная работа для парсера из `docs/tariff-updater-spec-v2.md` (ветка `docs/tariff-updater-spec-v2-october`, PR #1).

## 5. Как применить обновление (инструкция)

```bash
# 1. На dev-стенде: обновить код плагина
cd /var/www/<dev-site>/wp-content/plugins/mistersaver-tariff-map
git fetch && git checkout main && git pull        # после мержа PR

# 2. Импорт данных (обновит ACF-поля 89 регионов, post_content не трогает)
wp ms-tariffs import --path=/var/www/<dev-site>
wp ms-tariffs status

# 3. Сброс кешей (импортёр сбрасывает REST-кеш сам; при наличии page cache — очистить его)
wp ms-tariffs flush-cache

# 4. ВАЖНО: тексты регионов, сгенерированные LLM ранее, содержат «4% с 1 июля 2026».
#    Импорт их не перезаписывает. Перегенерировать:
wp ms-tariffs generate-content --slug=moskva --force   # проверить на одном регионе
wp ms-tariffs generate-content --force                 # затем все (~$1–2 на OpenRouter)

# 5. Проверить /tarify-zhku/, /tarify-zhku/moskva/, /wp-json/mistersaver/v1/regions
# 6. Повторить шаги 1–4 на проде
```
